# First run, part 1: the proof and the logic. Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put a debug build on a Googlebook that answers what first run rests on (the real panel behind the system's Keyboard shortcuts dialog, who starts the panel, whether the system's own words can be read, which keyboard has the Quick Insert key, what a tall glass redrawn every frame costs), and build first run's whole logic, its stored state and its debug hooks, tested, with nothing of it drawn yet.

**Architecture:** Everything first run decides is one pure object in `core/`, `FirstRun`: a `State` goes in, the screen that stands, the counter, and the state after an answer come out. The app keeps that state as five new fields of `Settings` (schema 7), maps it in and out with two functions, and shows and sets it through `./bl debug first …`; no user sees a change. The proof is three throwaway files in `overlay/` and a few lines behind `BuildConfig.DEBUG`, all of which part 2 removes.

**Tech Stack:** Kotlin 2.4, JUnit 4 in `core/` (plain JVM, no `android.*`), Jetpack Compose and an AGSL `RuntimeShader` in `app/` (compile SDK 37, min SDK 34), `kotlinx.serialization` for the settings file, the repo's own `./bl` helper over adb.

**Spec:**
- `docs/design/first-run/00-brief.md`, the section **"Settled for the build"**: it wins over every other paper.
- `docs/design/first-run/design.md` (§5 the key and the dialog's five rows, §6 the lessons and "Practice only", §9 progress and leaving, §10 states, §11 the replay).
- `docs/design/first-run/eng.md` (§1 to §3 and §8, as corrected by its §12 and §13 and by the settled list), `pm.md` §6, `motion.md`.
- `docs/research/shortcut-setup.md` §2 and §3 (what the dialog does, the Quick Insert key).

**Decided here, where the papers differ or are silent** (each is in the code and its tests below):
1. *An unfinished run* is counted per run, not per step: it stands in three openings, then waits in the Booklight window with what was done kept (`eng.md` §12.1; `pm.md` §6 and `design.md` §9 still say "per step").
2. *Practice* holds in every lesson, also out of turn: while L2, L3 or L4 stands, an app's Open and a search inside an app start nothing; anything else (a settings page, the web) is as every day.
3. *"Slow, once"* belongs to the opening piece: the opening that the welcome begins is the slow one, so it is slow exactly as often as the welcome is shown.
4. *The mark that step 1 is over* lives in `Settings.tipsSeen` as the id `first:key`, because a build from before first run drops first run's own fields when it writes the settings and keeps that list whole.
5. *The dialog's rows* each take their own `%1$s` (design.md §5 numbers the three words `%1$s` to `%3$s` across the rows).

- [ ] **Step 1: Write `Proof.kt`**

```kotlin
package io.github.kuscher.booklight.overlay

import android.app.Activity
import android.content.Intent
import android.net.Uri
import android.os.SystemClock
import android.util.Log
import android.view.InputDevice
import android.view.KeyEvent
import android.view.KeyboardShortcutGroup
import android.view.KeyboardShortcutInfo
import io.github.kuscher.booklight.BooklightApp
import io.github.kuscher.booklight.R

/**
 * THE PROOF (first run, milestone 0), first piece. Debug builds only, and only on the way to the real thing:
 * every call of it stands behind `BuildConfig.DEBUG`, and this file goes when step 1 is built (the plan's part 2).
 *
 * What it is there to show on a device: that the real panel, kept alive (`./bl open stay`), gets its own page in
 * the system's Keyboard shortcuts dialog (`./bl debug proof-helper`); which signals the panel is given while the
 * dialog is over it and when it goes; and who the system says started the panel when the new key is pressed.
 * Everything is said in the log (`./bl logs`), each line with the ms since the first one: the order is the finding.
 */
object Proof {
    /** Which key the rows carry: `quick`, `m`, or `auto` (Quick Insert where the keyboard the system names has it). */
    @Volatile var key = "auto"
    private val since = SystemClock.uptimeMillis()

    fun note(what: String) { Log.i(BooklightApp.TAG, "proof +${SystemClock.uptimeMillis() - since}ms $what") }

    /** The five rows of the dialog's page (docs/design/first-run/design.md §5), each with the suggested keys at its end. */
    fun rows(a: Activity, data: MutableList<KeyboardShortcutGroup>, deviceId: Int) {
        val has = InputDevice.getDevice(deviceId)?.hasKeys(KeyEvent.KEYCODE_CONTEXTUAL_INSERT)?.firstOrNull()
        val quick = when (key) { "quick" -> true; "m" -> false; else -> has == true }
        val code = if (quick) KeyEvent.KEYCODE_CONTEXTUAL_INSERT else KeyEvent.KEYCODE_M
        val labels = listOf(
            a.getString(R.string.first_helper_1, a.getString(R.string.first_sys_customize)),
            a.getString(R.string.first_helper_2),
            a.getString(R.string.first_helper_3, a.getString(if (quick) R.string.first_key_quick else R.string.first_key_letter)),
            a.getString(R.string.first_helper_4, a.getString(R.string.first_sys_set)),
            a.getString(R.string.first_helper_5),
        )
        data.add(KeyboardShortcutGroup(a.getString(R.string.first_helper_title), labels.map { KeyboardShortcutInfo(it, code, KeyEvent.META_META_ON) }))
        note("rows asked: deviceId=$deviceId quickInsert=$has rows=${if (quick) "quick" else "m"}")
    }

    /** Who started the panel: what the intent is (its extras by name only, never their text), and who the system says sent it. */
    fun started(how: String, intent: Intent, referrer: Uri?, byKey: Boolean, fromIcon: Boolean) {
        note("start ($how): action=${intent.action} categories=${intent.categories} flags=0x${Integer.toHexString(intent.flags)} extras=${intent.extras?.keySet()} bounds=${intent.sourceBounds != null} referrer=$referrer byKey=$byKey fromIcon=$fromIcon")
    }
}
```

- [ ] **Step 1: Write `ProofWords.kt`**

```kotlin
package io.github.kuscher.booklight.overlay

import android.app.LocaleManager
import android.content.Context
import android.content.res.Configuration
import android.content.res.Resources
import android.os.SystemClock
import android.view.InputDevice
import android.view.KeyCharacterMap
import android.view.KeyEvent

/**
 * THE PROOF (first run, milestone 0), second piece. Debug builds only; it goes with the plan's part 2, where
 * what it finds decides how the real thing quotes the system's buttons.
 *
 * Can an ordinary app read the words the system's Keyboard shortcuts dialog shows ("Customize", "Set
 * shortcut"), in the system's own language? Where does the dialog take the name "Quick Insert" from? And what
 * does the system say each attached keyboard has?
 */
object ProofWords {
    const val SYSTEM_UI = "com.android.systemui"
    /** The names AOSP gives the dialog's own words (docs/research/shortcut-setup.md §2). */
    private val NAMES = listOf(
        "shortcut_helper_customize_button_text", "shortcut_helper_customize_dialog_set_shortcut_button_label",
        "shortcut_helper_title", "shortcut_helper_customizer_action_key_text", "shortcut_helper_done_button_text",
    )

    /** Another app's resources in the system's own languages (Booklight can be set to another one), or why they cannot be had. */
    private fun resources(context: Context, pkg: String): Result<Resources> = runCatching {
        val pm = context.packageManager
        val system = context.getSystemService(LocaleManager::class.java).systemLocales
        pm.getResourcesForApplication(pm.getApplicationInfo(pkg, 0), Configuration(context.resources.configuration).apply { setLocales(system) })
    }

    /** One line: each name with the word the system has for it, or the reason there is none. [more]: further names to read. */
    fun words(context: Context, more: List<String>): String {
        val t0 = SystemClock.uptimeMillis()
        val res = resources(context, SYSTEM_UI)
        val read = (NAMES + more).joinToString(" | ") { name ->
            name + "=" + res.fold({ r ->
                val id = r.getIdentifier(name, "string", SYSTEM_UI)
                if (id == 0) "(no such name)" else runCatching { "'" + r.getString(id) + "'" }.getOrElse { "(${it.javaClass.simpleName})" }
            }, { "(${it.javaClass.simpleName})" })
        }
        // Is a package signed with the platform's key visible without a line in <queries>? The shell's is one, and has no such line.
        val shell = runCatching { context.packageManager.getApplicationInfo("com.android.shell", 0) }.isSuccess
        val system = context.getSystemService(LocaleManager::class.java).systemLocales.toLanguageTags()
        return "$read | visible-without-queries(com.android.shell)=$shell system=$system booklight=${context.resources.configuration.locales.toLanguageTags()} took=${SystemClock.uptimeMillis() - t0}ms"
    }

    /**
     * Where a word comes from: the names of every string of [pkg] (`android` is the platform itself) whose value
     * is [text], in the system's own languages. It tries every id of the package's strings, so it is slow: never on
     * the main thread.
     */
    fun find(context: Context, pkg: String, text: String): List<String> {
        val platform = pkg == "android"
        val res = (if (platform) Result.success(Resources.getSystem()) else resources(context, pkg)).getOrElse { return listOf("(${it.javaClass.simpleName})") }
        val out = ArrayList<String>()
        for (type in 1..0x3f) {
            val first = ((if (platform) 0x01 else 0x7f) shl 24) or (type shl 16)
            if ((0..15).firstNotNullOfOrNull { runCatching { res.getResourceTypeName(first or it) }.getOrNull() } != "string") continue
            // (The ids of one kind follow one another: a long gap is the end.)
            var misses = 0
            var entry = 0
            while (entry < 0x10000 && misses < 512) {
                val id = first or entry++
                val value = runCatching { res.getString(id) }.getOrNull()
                if (value == null) { misses++; continue }
                misses = 0
                if (value.equals(text, ignoreCase = true)) out += runCatching { res.getResourceEntryName(id) }.getOrDefault("?")
            }
        }
        return out
    }

    /** What the system says each attached keyboard is and has. By its number only: a keyboard's name is nobody's business here. */
    fun keyboards(): List<String> = InputDevice.getDeviceIds().toList().mapNotNull { InputDevice.getDevice(it) }.filter { it.supportsSource(InputDevice.SOURCE_KEYBOARD) }.map { d ->
        val has = d.hasKeys(KeyEvent.KEYCODE_CONTEXTUAL_INSERT, KeyEvent.KEYCODE_M, KeyEvent.KEYCODE_CAPS_LOCK)
        "id=${d.id} external=${d.isExternal} virtual=${d.isVirtual} alphabetic=${d.keyboardType == InputDevice.KEYBOARD_TYPE_ALPHABETIC} quickInsert=${has[0]} m=${has[1]} capsLock=${has[2]}"
    } + "any keyboard: quickInsert=${KeyCharacterMap.deviceHasKey(KeyEvent.KEYCODE_CONTEXTUAL_INSERT)}"
}
```

```kotlin
/**
 * THE PROOF (first run, milestone 0), third piece. Debug builds only; it goes with the plan's part 2.
 *
 * What does a tall glass cost that is redrawn every frame, next to the window's blur? The welcome wants 720 × 468 dp
 * with light and drawing in it for four seconds; nobody has measured such a thing. `./bl debug proof-glass MODE`
 * grows the glass to that height, redraws it for four seconds in one of five ways, and logs what the window's
 * frames took (the platform's own frame metrics: the whole frame, the part on the graphics chip, and how many
 * missed their deadline).
 */
object ProofGlass {
    /**
     * `tall`: the glass grown, nothing redrawn. `light`: the glass's own shader every frame (the light of the model at
     * work). `shader`: a second shader over all of it, a shaft of light. `canvas`: 150 moving marks. `both`: those two.
     */
    val MODES = listOf("tall", "light", "shader", "canvas", "both")
    /** The mode that runs; null: none. Read where the panel's height is worked out, so the glass grows with it. */
    var mode by mutableStateOf<String?>(null)
        private set
    val TALL = 468.dp
    private const val RUN_MS = 4000L
    /** The frames in which the glass grows are not the ones asked about. */
    private const val GROW_MS = 600L

    /** Runs [what] in [activity]'s panel and logs the result when it is over. What it answers at once goes to the debug hook. */
    fun run(activity: OverlayActivity, what: String): String {
        if (what !in MODES) return MODES.joinToString(" | ")
        if (mode != null) return "one is running"
        val main = Handler(Looper.getMainLooper())
        val window = activity.window
        val total = ArrayList<Long>()
        val gpu = ArrayList<Long>()
        var late = 0
        var unreported = 0
        val listener = Window.OnFrameMetricsAvailableListener { _, m, dropped ->
            val t = m.getMetric(FrameMetrics.TOTAL_DURATION)
            total += t
            gpu += m.getMetric(FrameMetrics.GPU_DURATION)
            if (t > m.getMetric(FrameMetrics.DEADLINE)) late++
            unreported += dropped
        }
        mode = what
        if (what == "light") activity.model.pretendThinking(true)
        main.postDelayed({ window.addOnFrameMetricsAvailableListener(listener, main) }, GROW_MS)
        main.postDelayed({
            window.removeOnFrameMetricsAvailableListener(listener)
            if (what == "light") activity.model.pretendThinking(false)
            mode = null
            fun ms(ns: Long) = "%.1f".format(Locale.ROOT, ns / 1_000_000.0)
            fun at(all: List<Long>, share: Double) = all.sorted().let { if (it.isEmpty()) 0L else it[((it.size - 1) * share).toInt()] }
            val hz = activity.display?.refreshRate ?: 0f
            Log.i(BooklightApp.TAG, "proof glass $what: frames=${total.size} (the screen draws ${hz.toInt()} a second: ${(hz * RUN_MS / 1000f).toInt()} in the time) · " +
                "whole frame p50=${ms(at(total, 0.5))} p90=${ms(at(total, 0.9))} p99=${ms(at(total, 0.99))} max=${ms(total.maxOrNull() ?: 0L)} ms · " +
                "graphics chip p50=${ms(at(gpu, 0.5))} p99=${ms(at(gpu, 0.99))} ms · past their deadline=$late · not reported=$unreported")
        }, GROW_MS + RUN_MS)
        return "$what runs for ${RUN_MS / 1000} s: its line comes in ./bl logs"
    }
}

/** A shaft of light as a shader over the whole glass: for each pixel about what the glass's own reflection costs (a few smooth steps, one exponential, one hash). */
private const val SHAFT = """
uniform float2 size;
uniform float t;          // seconds since it began
float hash(float2 p) { return fract(sin(dot(p, float2(12.9898, 78.233))) * 43758.5453); }
half4 main(float2 xy) {
    float2 p = xy / size;
    float x = p.x - 0.5 - 0.08 * sin(t * 1.3);
    float w = 0.06 + 0.34 * p.y;
    float side = 1.0 - smoothstep(0.6 * w, w, abs(x));
    float core = exp(-x * x / (0.002 + 0.02 * p.y * p.y));
    float fall = 1.0 - 0.6 * p.y;
    float a = clamp((0.10 * side + 0.16 * core) * fall + (hash(xy + t) - 0.5) * 0.01, 0.0, 1.0);
    return half4(a, a, a, a);
}
"""

/** The proof's drawing, over the whole glass, while one of its drawing modes runs. `Panel` calls it in debug builds only. */
@Composable
fun ProofLayer() {
    val what = ProofGlass.mode ?: return
    val shade = what == "shader" || what == "both"
    val marks = what == "canvas" || what == "both"
    if (!shade && !marks) return      // `tall` and `light` draw nothing of their own
    var time by remember { mutableFloatStateOf(0f) }
    LaunchedEffect(Unit) {
        val start = withFrameNanos { it }
        while (true) time = (withFrameNanos { it } - start) / 1_000_000_000f
    }
    // (A shader that does not compile must not take the panel down: the log says so, and that mode draws nothing.)
    val shader = remember { runCatching { RuntimeShader(SHAFT) }.onFailure { Log.w(BooklightApp.TAG, "proof glass: the shader did not compile (${it.message})") }.getOrNull() }
    Box(Modifier.fillMaxSize().drawWithCache {
        val brush = shader?.let { ShaderBrush(it) }
        onDrawBehind {
            if (shade && shader != null && brush != null) {
                shader.setFloatUniform("size", size.width, size.height)
                shader.setFloatUniform("t", time)
                drawRect(brush)
            }
        }
    }) {
        if (marks) Canvas(Modifier.fillMaxSize()) {
            val t = time
            for (i in 0 until 150) {
                val x = size.width * (0.5f + 0.45f * sin(t * (0.4f + i * 0.011f) + i))
                val y = size.height * (0.5f + 0.45f * cos(t * (0.3f + i * 0.007f) + i * 2f))
                drawCircle(Color.White.copy(alpha = 0.10f), radius = (2f + i % 5).dp.toPx(), center = Offset(x, y))
            }
        }
    }
}
```

```kotlin
package io.github.kuscher.booklight.core

/**
 * First run: Booklight is given a key, three things are tried once, one question is answered and
 * two choices are offered, under the empty field where a card stood. Everything that is decided
 * about it is decided here: which screen stands at the next opening, what an answer changes, who
 * gets a run at all. The app keeps a [State] in its settings and draws what [screen] says; nothing
 * here knows Android.
 *
 *  - **A run** belongs to a new installation ([Run.NEW]: every step), to one that was there before
 *    and has no key yet ([Run.UPDATE]: the key alone), or was asked for again ([Run.REPLAY]).
 *  - **A step** is over once it was done, skipped or answered ([State.done]); the next one stands.
 *  - **An unfinished run** stands in [MAX_OPENS] openings. After that it waits in the Booklight
 *    window, with what was done kept, until it is asked for ([resume]).
 */
object FirstRun {
    /** Which run an installation is in. Kept in the settings as its number ([id]). */
    enum class Run(val id: Int) {
        NONE(0), NEW(1), UPDATE(2), REPLAY(3);

        companion object {
            /** The run a stored number stands for; a number nobody knows is no run. */
            fun of(id: Int): Run = entries.firstOrNull { it.id == id } ?: NONE
        }
    }

    /** The steps, in their order. [id] is how a step is kept once it is over. */
    enum class Step(val id: String) { KEY("key"), OPEN("open"), SEARCH("search"), SUM("sum"), ASK("ask"), CHOICES("choices") }

    /**
     * What stands under the empty field. K1 asks for the key; K2 is back from the system's dialog
     * without one; K3 is back again; K4: the key works. L2 to L4 are the lessons, Q the question,
     * C the choices.
     */
    enum class Screen(val step: Step) {
        K1(Step.KEY), K2(Step.KEY), K3(Step.KEY), K4(Step.KEY), L2(Step.OPEN), L3(Step.SEARCH), L4(Step.SUM), Q(Step.ASK), C(Step.CHOICES)
    }

    /**
     * What is kept. [done]: the ids of the steps that are over, and two words that are no steps
     * ([SHOWN], [CHANGE]). [opens]: in how many openings this run has stood. [helper]: how often the
     * system's dialog came over the panel for the key. [icon]: the icon's first click has shown the
     * panel. [key]: a key has opened the panel, ever. [suggestions]: search suggestions are on.
     * [mark]: step 1 is over on this installation, however it ended.
     */
    data class State(
        val run: Run = Run.NONE,
        val done: List<String> = emptyList(),
        val opens: Int = 0,
        val helper: Int = 0,
        val icon: Boolean = false,
        val key: Boolean = false,
        val suggestions: Boolean = false,
        val mark: Boolean = false,
    )

    /** In [State.done]: the opening (the welcome and the show) has been shown in this run. */
    const val SHOWN = "show"
    /** In [State.done]: a replay asks for the key again although one is known ("Change the key"). */
    const val CHANGE = "change"
    /** An unfinished run stands in this many openings, then waits in the Booklight window. */
    const val MAX_OPENS = 3
    /** The least screen height, in dp, at which first run stands in the panel (its tallest screen is 324 dp). */
    const val MIN_SCREEN_DP = 475f

    private fun over(s: State, step: Step) = step.id in s.done

    /**
     * The steps this run has. The run of an installation that was there before is the key alone.
     * The question is a step only while suggestions are off, or once it was answered in this run.
     */
    fun steps(s: State): List<Step> = when (s.run) {
        Run.NONE -> emptyList()
        Run.UPDATE -> listOf(Step.KEY)
        Run.NEW, Run.REPLAY -> Step.entries.filter { it != Step.ASK || !s.suggestions || over(s, Step.ASK) }
    }

    /** The step whose turn it is; null: there is no run, or nothing is left of it. */
    fun step(s: State): Step? = steps(s).firstOrNull { !over(s, it) }

    /** The run has stood in [MAX_OPENS] openings and was not finished: it waits in the Booklight window. */
    fun parked(s: State): Boolean = s.run != Run.NONE && s.opens > MAX_OPENS

    /** What stands under the empty field; null: nothing of first run. */
    fun screen(s: State): Screen? {
        if (parked(s)) return null
        return when (step(s) ?: return null) {
            Step.KEY -> when {
                s.key && CHANGE !in s.done -> Screen.K4
                s.helper == 0 -> Screen.K1
                s.helper == 1 -> Screen.K2
                else -> Screen.K3
            }
            Step.OPEN -> Screen.L2
            Step.SEARCH -> Screen.L3
            Step.SUM -> Screen.L4
            Step.ASK -> Screen.Q
            Step.CHOICES -> Screen.C
        }
    }

    /**
     * "2 of 5": where the screen that stands is in its run. Null where no counter stands: on the
     * choices, which are the last screen, and in a run of one step.
     */
    fun count(s: State): Pair<Int, Int>? {
        val on = screen(s) ?: return null
        val counted = steps(s).filter { it != Step.CHOICES }
        if (on == Screen.C || counted.size < 2) return null
        return counted.indexOf(on.step) + 1 to counted.size
    }

    /** Whether first run stands in the panel on a screen this high; on a lower one the Booklight window's Start page has the key's row. */
    fun fits(screenDp: Float): Boolean = screenDp >= MIN_SCREEN_DP
}
```

```kotlin
    // ---- answers

    /** What can be answered. [DONE]: the choices were left, however they were left. */
    enum class Answer { NOT_NOW, GO_ON, CHANGE_KEY, SKIP, AGREE, DONE }

    private fun finish(s: State, step: Step): State = if (over(s, step)) s else s.copy(done = s.done + step.id)

    /** The run is over: nothing of it is kept but that step 1 has ended on this installation. */
    private fun ended(s: State): State = s.copy(run = Run.NONE, done = emptyList(), opens = 0, helper = 0, mark = true)

    /** A run with no step left is over. */
    private fun settle(s: State): State = if (s.run != Run.NONE && step(s) == null) ended(s) else s

    /**
     * [s] after [answer] was given on the screen that stands. An answer that screen does not offer
     * changes nothing. "Not now" on the key ends the run; on the question it is an answer like
     * another. Suggestions are switched on in one place only: [Answer.AGREE] on the question.
     */
    fun answer(s: State, answer: Answer): State {
        val on = screen(s) ?: return s
        return settle(when (on) {
            Screen.K1, Screen.K2, Screen.K3 -> if (answer == Answer.NOT_NOW) ended(s) else s
            Screen.K4 -> when (answer) {
                Answer.GO_ON -> finish(s, Step.KEY).copy(mark = true)
                Answer.CHANGE_KEY -> if (s.run == Run.REPLAY) s.copy(done = s.done + CHANGE, helper = 0) else s
                else -> s
            }
            Screen.L2, Screen.L3, Screen.L4 -> if (answer == Answer.SKIP) finish(s, on.step) else s
            Screen.Q -> when (answer) {
                Answer.AGREE -> finish(s, Step.ASK).copy(suggestions = true)
                Answer.NOT_NOW -> finish(s, Step.ASK)
                else -> s
            }
            Screen.C -> if (answer == Answer.DONE) finish(s, Step.CHOICES) else s
        })
    }

    /**
     * The key opened the panel, or uncovered it under the system's dialog. A key that was known
     * already changes nothing, unless the run was asking for another one. A run that waited comes
     * back: the first press of the user's own key is what first run is for.
     */
    fun keyLanded(s: State): State {
        if (s.key && CHANGE !in s.done) return s
        val t = s.copy(key = true)
        if (s.run == Run.NONE || over(s, Step.KEY)) return t
        return t.copy(done = t.done - CHANGE, helper = 0, opens = 0)
    }

    /** The system's dialog came over the panel while it asked for the key. */
    fun helperCame(s: State): State = when (screen(s)) {
        Screen.K1, Screen.K2, Screen.K3 -> s.copy(helper = s.helper + 1)
        else -> s
    }
```

```kotlin
    /**
     * A screen of this run comes in a new opening: counted once for each panel, at the moment it
     * comes. Past [MAX_OPENS] the run waits ([parked]) and nothing comes.

    fun opened(s: State): State = if (s.run == Run.NONE || step(s) == null || parked(s)) s else s.copy(opens = s.opens + 1)

     * first (the Booklight window's row); without it where the user is at work in the panel.
     */
    fun replay(s: State, overture: Boolean): State =
        s.copy(run = Run.REPLAY, done = if (overture) emptyList() else listOf(SHOWN), opens = 0, helper = 0)

    /** "First steps" was asked for: an unfinished run goes on where it stopped, a finished one is played again. */
    fun again(s: State, overture: Boolean): State = if (s.run != Run.NONE) resume(s) else replay(s, overture)

    /**
     * For the debug hooks: [s] moved to where [wanted] stands, without touching whether a key is
     * known or whether suggestions are on. Null where that cannot be: "Your key works" without a
     * key, the question with suggestions on.
     */
    fun at(s: State, wanted: Screen): State? {
        val run = if (s.run == Run.NEW || s.run == Run.REPLAY) s.run else Run.REPLAY
        val before = Step.entries.takeWhile { it != wanted.step }.map { it.id }
        val base = s.copy(run = run, done = before + SHOWN, opens = 0, helper = 0)
        val to = when (wanted) {
            Screen.K1, Screen.K2, Screen.K3 -> base.copy(done = if (s.key) base.done + CHANGE else base.done, helper = wanted.ordinal)
            else -> base
        }
        return to.takeIf { screen(it) == wanted }
    }
```

```kotlin
    /**
```

```kotlin
     * the row belongs to (the app's `Guide.used`: `appsearch`, `sums`, `settings`…), or null.
     * [searchable]: an app of this device can be searched; where none can, a settings page found
     * under the Settings keyword stands in for lesson 3. A lesson's thing counts whichever lesson
     * stands. Making an app the chip (Search on its row) is no practice: it is done for real.
     */
    fun enters(s: State, line: String?, effect: Effect, searchable: Boolean): Enter {
        val on = screen(s)
        if (on != Screen.L2 && on != Screen.L3 && on != Screen.L4) return Enter.AS_ALWAYS
        return when {
            effect is Effect.LaunchApp -> Enter.PRACTICE_OPEN
            line == "appsearch" && effect is Effect.Open -> Enter.PRACTICE_SEARCH
            !searchable && line == "settings" && effect is Effect.OpenSettings -> Enter.PRACTICE_SEARCH
            line == "sums" && effect is Effect.CopyText -> Enter.COPY_STAYS
```

```kotlin
    // ---- the start

    /** How an opening begins. [SHOW]: Booklight uses itself, then the key's screen. [WELCOME]: the welcome first, then the show. */
    enum class Overture { NONE, SHOW, WELCOME }

    /** The least screen height, in dp, for the welcome: its glass is 468 dp high. */
    const val WELCOME_SCREEN_DP = 655f

    /**
     * Whether this opening begins with the opening piece: once, on the very first start of a new
     * installation, and again where a replay asks for it. [motion]: the system's animations are on.
     * [reader]: a screen reader is on. [plain]: the start carries no text from another app. Asking
     * uses nothing up: [shown] does.
     */
    fun overture(s: State, motion: Boolean, reader: Boolean, plain: Boolean, screenDp: Float): Overture = when {
        !motion || reader || !plain || !fits(screenDp) -> Overture.NONE
        s.run != Run.NEW && s.run != Run.REPLAY -> Overture.NONE
        SHOWN in s.done || parked(s) || step(s) != Step.KEY -> Overture.NONE
        screenDp >= WELCOME_SCREEN_DP -> Overture.WELCOME
        else -> Overture.SHOW
    }

    /** The opening piece has ended, or has played for two seconds: it does not come again in this run. */
    fun shown(s: State): State = if (SHOWN in s.done) s else s.copy(done = s.done + SHOWN)

    /** The very first opening of a new installation, the one its opening piece begins, runs at the Slow speed whatever is set. */
    fun slow(s: State, overture: Overture): Boolean = s.run == Run.NEW && overture != Overture.NONE

    /** The key suggested beside Action. */
    enum class Key { QUICK_INSERT, M }

    /** A keyboard that is attached. [external]: not the device's own. [quickInsert]: it has the Quick Insert key. */
    data class Keyboard(val id: Int, val external: Boolean, val quickInsert: Boolean)

    /**
     * Whether the keyboard in front has the Quick Insert key: the one the last key came from
     * ([last], its id); before any key, the device's own; with neither, the first there is. No
     * keyboard known: no.
     */
    fun hasQuickInsert(keyboards: List<Keyboard>, last: Int?): Boolean =
        (keyboards.firstOrNull { it.id == last } ?: keyboards.firstOrNull { !it.external } ?: keyboards.firstOrNull())?.quickInsert ?: false

    /** Action + Quick Insert where the keyboard has that key; Action + M where it has not. */
    fun suggest(quickInsert: Boolean): Key = if (quickInsert) Key.QUICK_INSERT else Key.M

    /** The other keys to try when the suggested ones did not work: Action + M after Quick Insert; after M, nothing more. */
    fun other(suggested: Key): Key? = if (suggested == Key.QUICK_INSERT) Key.M else null
```

```kotlin
                        val run = when (words[0]) { "new" -> FirstRun.Run.NEW; "update" -> FirstRun.Run.UPDATE; else -> FirstRun.Run.NONE }
                        val t = if (run == FirstRun.Run.NONE) s else s.copy(tipsSeen = s.tipsSeen - FirstRun.MARK)
                        t.withFirstRun(t.firstRun().copy(run = run, done = emptyList(), opens = 0, helper = 0, icon = false))
                    }
                    "replay" -> put(FirstRun.replay(was, overture = words.getOrNull(1) == "show"))
                    "resume" -> put(FirstRun.resume(was))
                    "key" -> put(FirstRun.keyLanded(was))
                    "helper" -> put(FirstRun.helperCame(was))
                    "opened" -> put(FirstRun.opened(was))
                    "shown" -> put(FirstRun.shown(was))
                    "answer" -> {
                        val answer = FirstRun.Answer.entries.firstOrNull { it.name.equals(words.getOrNull(1), ignoreCase = true) }
                            ?: return out(FirstRun.Answer.entries.joinToString(" ") { it.name.lowercase() })
                        put(FirstRun.answer(was, answer))
                    }
                    "ran" -> put(FirstRun.ran(was, when (words.getOrNull(1)) {
                        "open" -> FirstRun.Enter.PRACTICE_OPEN; "search" -> FirstRun.Enter.PRACTICE_SEARCH; "sum" -> FirstRun.Enter.COPY_STAYS
                        else -> return out("open search sum")
                    }))
                    "at" -> {
                        val screen = FirstRun.Screen.entries.firstOrNull { it.name.equals(words.getOrNull(1), ignoreCase = true) }
                            ?: return out(FirstRun.Screen.entries.joinToString(" ") { it.name.lowercase() })
                        put(FirstRun.at(was, screen) ?: return out("${screen.name} cannot stand: K4 needs a key (`first key`), Q needs suggestions off"))
                    }
                    // As if an older build had written the settings and this one read them again: what that build does not know is gone, and the
                    // migration runs anew.
                    "older" -> app.prefs.update { it.asUpdate() }
                    else -> return out("new | update | off | replay [show] | resume | key | helper | opened | shown | answer NAME | ran open|search|sum | at SCREEN | older")
                }
                val f = app.prefs.now.firstRun()
                val dp = context.getSystemService(android.view.WindowManager::class.java).maximumWindowMetrics.bounds.height() / context.resources.displayMetrics.density
                val motion = io.github.kuscher.booklight.overlay.Motion.of(context).on
                val reader = context.getSystemService(android.view.accessibility.AccessibilityManager::class.java).isTouchExplorationEnabled
                val overture = FirstRun.overture(f, motion, reader, plain = true, screenDp = dp)
                val boards = io.github.kuscher.booklight.device.Keyboards.attached()
                val key = FirstRun.suggest(FirstRun.hasQuickInsert(boards, null))
                out("run=${f.run} done=${f.done} opens=${f.opens} helper=${f.helper} icon=${f.icon} key=${f.key} suggestions=${f.suggestions} mark=${f.mark} | " +
                    "parked=${FirstRun.parked(f)} screen=${FirstRun.screen(f)} count=${FirstRun.count(f)?.let { "${it.first}/${it.second}" }} | " +
                    "overture=$overture slow=${FirstRun.slow(f, overture)} fits=${FirstRun.fits(dp)} (${dp.toInt()} dp high, animations=$motion, reader=$reader) | " +
                    "suggested=$key other=${FirstRun.other(key)} keyboards=${boards.joinToString(",") { (if (it.external) "external" else "own") + (if (it.quickInsert) "+quick" else "") }.ifEmpty { "none" }}")
            }
```
