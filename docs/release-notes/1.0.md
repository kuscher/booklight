# Booklight 1.0

The first release: a keyboard launcher for Googlebooks. Press your shortcut, a small glass panel appears
over your desktop, type a few letters, press Enter.

- **Apps first.** The start of a name, the start of any word in it, initials, or a few loose letters.
- **It learns.** What you pick for the text you typed comes first next time.
- **Settings pages, sums and the web.** "dark", `150 + 20%`, a typed address, or a search. A keyword
  searches one site: `yt lofi`.
- **More per row.** Tab lists what else a row can do.
- **Glass and motion.** The panel takes your wallpaper's colors; the selection glides and lists cascade in.
- **Search suggestions are off until you turn them on.** With them on, what you type goes to your search
  engine to suggest searches.
- English and German.

## Install
1. Download **Booklight.apk** below and open it from Files. If Android asks, allow Files to install apps.
2. Open Booklight once. It shows how to give it a key: Keyboard shortcuts › App shortcuts › Add shortcut.
   The system wants the Action key in every shortcut; Action + Alt + Space and Action + K are free.
